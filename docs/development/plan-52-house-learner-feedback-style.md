## Bounded implementation after approval

- Success: one short acknowledgment, e.g. “That's right.” or “All placed correctly.”
  Compact pale-green treatment, readable dark text and modest emphasis based on
  accepted Plan50/unary styling. Replace only a completed instruction; retain
  accepted mathematics and a genuinely active reflection or next responsibility.
- Retry: consistent subdued recovery treatment and brief non-blaming next action,
  specific where the existing classification supports it. Preserve useful text
  such as amount-preservation feedback; do not replace it with generic praise/retry.
- Incomplete: neutral next-action guidance, never a mathematical error verdict.
  Help remains optional/neutral or accent-soft. Valid-but-unavailable work and
  navigation failure remain truthful attention near the relevant action, not a
  red assertion that correct mathematics is wrong.
- Small shared feedback CSS/helper ownership is allowed; a generic renderer,
  framework, global focus rewrite, new state/classification/replay meaning, lesson
  redesign, new tasks/content or extra progression step is not. No prototype-only
  subtraction-page migration in this packet.
- Preserve visible focus, feedback associations and one deliberate announcement
  path per outcome. Do not add messages/focus movement after every transition or
  duplicate a focused message as identical live-region/heading text. Verify both
  access paths; do not claim screen-reader speech without actual observation.
