## Requirement 2 — short mounted session

Provide one optional, plainly labeled entry, e.g. “Compare fractions, then find a
distance.” Keep standalone goals available; do not present a learner level test.
No compulsory introduction, duplicate session heading/task prompt or long prerequisite
paragraph. Give a concise truthful cue that session position is not saved; don't
promise durable continuation or a browser exit warning.

Launch existing tasks with fixed selected support configuration where admitted;
task-specific aids remain truthful. Comparison's optional denominator help does not
become distance help, and distance's high-support cue is not independent work.
Preserve selected visual/linear mode and reduced-motion preferences across transitions,
but start a fresh per-episode draft/help state and retain provenance with its episode.
No performance-triggered level change or inference from completion.

After acceptance retain result until deliberate Next. At the third accepted item,
use a concise truthful forward cue such as “Next: compare and find the distance,”
then launch the NEW pair directly. The fourth task asks its own relation once then
distance; do not reuse previous equality, bypass its comparison or add a transition
screen/question. Equality/unit/task changes are intentional, not claimed single-variable.

Final accepted distance stays inspectable with one modest completion acknowledgment
and Back to practice. No empty Finish, fake Next, auto-advance, score/streak or pressure.
First session start after completion begins the same manifest fresh.

Always allow early exit. Confirm only abandoning active unfinished work: concise
Stay/Leave choice; Stay retains exact current state, draft, help and focus, Leave
returns to practice and clears session. No extra confirmation for accepted/final
results. Respect keyboard/dialog focus/return and avoid duplicate global exit paths.
Do not intercept tab close/reload with a misleading guarantee or global beforeunload
policy. Leaving/reloading discards session index/drafts; returning begins at first
record. No sessionStorage/localStorage/IndexedDB/cookie/remote writes for progress.
Existing unrelated accessibility preferences are not session progress.

If next preparation fails, retain old accepted result and index, show neutral
actionable attention and provide retry/return. Never clear old state, skip a record,
advance index on failure or label correct math wrong. Invalidate retired session
and episode controls on reset/exit/navigation; generation handles same-record restart.
Focus a meaningful target on successful task change, with no redundant announcements.

Installation-boundary clarification (2026-11-02 orchestration gate): expected
destination preparation/validation failure retains old work; exact rollback after
arbitrary post-commit renderer failure is not required. Preflight pure scene/capability
before commit. Unexpected display failure ends the session safely at practice entry
with neutral notice, no false completion/preservation claim and no stale controls.
See reports/development/plan-60-short-magnitude-practice-session/mounted-install-boundary-disposition.md.
No general detached staging/render transaction refactor is approved.
