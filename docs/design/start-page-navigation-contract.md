# Start-page navigation contract

Plan 67 organizes the existing admitted capabilities on the start page. The compact subtitle reads “Explore fractions with pictures and numbers.” When a featured goal is available, the noninteractive “Featured today” label appears immediately above its button. The primary action names a registered standalone goal, selected from an ordered cycle of unlike addition, comparison, number-line placement, and wholes/parts. The cycle uses the UTC calendar day sampled once per document and filters unavailable candidates. The choice is stable for that document, including return and remount; a fresh document samples again. If no featured candidate is available, the session action or Choose provides the next available path. “Choose what to practice” expands one initially closed region with Add and subtract, Compare and distance, Number lines, and Wholes and parts. The primary also appears in its group. Labels, items and standalone fragments come from the practice registry; the comparison/distance session remains a separate manifest without a resume fragment. Empty groups are omitted, and an empty featured candidate pool has no substitute. Invalid or unmapped capabilities are reported while valid mapped choices remain available. New capabilities require deliberate grouping and a separate record-coverage review.

With the chooser closed, keyboard order starts with the featured practice, Start a practice session, Choose, Settings, Practice record, and About. When the featured practice is unavailable, Start a practice session comes first if available. The session action opens the fixed four-comparison sequence from Plan 69. Opening the chooser places its goal buttons between Choose and Settings in document order. Toggling retains focus; closing while focus is inside moves it to Choose. Back to start closes the chooser and focuses the start heading. Entry preparation failure keeps the entry and chooser available; a display failure after installation begins returns to entry with a notice and permits a fresh attempt. Standalone direct fragments and the record's comparison action retain their existing launch identities. The session's place is not saved.

Settings and display applicability remain as before. The optional local comparison record, shell navigation, session exit policy, and saved observations are governed by [the app shell contract](app-shell-navigation-contract.md) and [Plan 63](../development/plan-63-optional-local-comparison-practice-record.md). This shared featured rotation does not schedule episodes, personalize practice, alter record eligibility, or add task content. Rendered owner acceptance and deployment are separate gates.
