# Start-page navigation contract

Plan 67 organizes the existing admitted capabilities on the start page. The primary action is the registered “Add fractions with different denominators” goal. “Choose what to practice” expands one initially closed region with Add and subtract, Compare and distance, Number lines, and Wholes and parts. The primary also appears in its group. Labels, items and standalone fragments come from the practice registry; the comparison/distance session remains a separate manifest without a resume fragment. Empty groups are omitted, and an unavailable primary is identified without a substitute. Invalid or unmapped capabilities are reported while valid mapped choices remain available. New capabilities require deliberate grouping and a separate record-coverage review.

With the chooser closed, keyboard order starts with primary, Choose, Settings, Practice record, and About. Opening the chooser places its goal buttons between Choose and Settings in document order. Toggling retains focus; closing while focus is inside moves it to Choose. Back to start closes the chooser and focuses the start heading. Entry preparation failure keeps the entry and chooser available; a display failure after installation begins returns to entry with a notice and permits a fresh attempt. Standalone direct fragments and the record's comparison action retain their existing launch identities. The session's place is not saved.

Settings and display applicability remain as before. The optional local comparison record, shell navigation, session exit policy, and saved observations are governed by [the app shell contract](app-shell-navigation-contract.md) and [Plan 63](../development/plan-63-optional-local-comparison-practice-record.md). This organization does not add scheduling, personalization, record eligibility, or task content. Rendered owner acceptance and deployment are separate gates.
